# Phases and docs tasks

Generated by `mise run docs:build` from the tasks themselves. Don't edit: `docs:test` fails when this is out of date.
Change a task's `#MISE description` (or a phase's description in mise.toml) instead.

Each task shows its flags and arguments. "(listed)" means `mise tasks` shows it. "Runs first" is what it runs before itself; for a phase, its steps in order.

## phases

| Task | What it does | Runs first | Timeout | File |
|---|---|---|---|---|
| `0:clean` (listed) | Remove everything local that setup and build make: app (node_modules, ui/dist, local D1 data), then the workers/icelight clone | `app:clean`, `icelight:clean` |  | `mise.toml` |
| `1:setup` (listed) | Get everything ready: check your Cloudflare credentials first, then app, icelight, icelight's token. Ends with 5:status | `cloudflare:status`, `app:setup`, `icelight:setup`, `icelight:token:setup`, `5:status` |  | `mise.toml` |
| `2:build` (listed) | Build everything: app (its UI), icelight (its packages and UI), then docs (the generated task reference) | `app:build`, `icelight:build`, `docs:build` |  | `mise.toml` |
| `3:test` (listed) | Every test that needs no deployment: app (types, 7 checks in Node, 7 in a temporary Worker), then docs (up to date, no broken links) | `app:test`, `docs:test` |  | `mise.toml` |
| `4:deploy` (listed) | Deploy everything to Cloudflare, in order: app (its Worker and D1 database), then icelight (Basin, both Workers, demo events) | `app:deploy`, `icelight:deploy` |  | `mise.toml` |
| `5:status` (listed) | Your Cloudflare credentials, every URL, and whether each Worker answers: app, icelight, icelight's token | `cloudflare:status`, `app:status`, `icelight:status`, `icelight:token:status` |  | `mise.toml` |
| `6:teardown` (listed) | Remove everything from Cloudflare, in order: icelight (its resources, data and token), then app (its Worker and D1 database) | `icelight:teardown`, `app:teardown` |  | `mise.toml` |

## docs

| Task | What it does | Runs first | Timeout | File |
|---|---|---|---|---|
| `docs:build` | Regenerate every docs/**/tasks.md from the tasks themselves: docs/tasks.md (phases, docs) and one per component in mise-tasks/ |  | 2m | `mise-tasks/docs/build` |
| `docs:test` | Fail if any docs/**/tasks.md is out of date with the tasks, or any link in README.md, PLAN.md or docs/ points at a missing file |  | 2m | `mise-tasks/docs/test` |
